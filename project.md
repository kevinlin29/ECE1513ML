
# Explainable AI for Network Intrusion Detection

## Overview

Modern network intrusion detection systems (IDS) use machine learning models to detect malicious network activity. While these models can achieve high detection accuracy, many of them operate as **black boxes**, making it difficult for security engineers to understand why a particular alert was triggered.

This project investigates the use of **Explainable Artificial Intelligence (XAI)** techniques to interpret machine learning decisions in intrusion detection systems. The goal is to build several ML models to detect network attacks and analyze their predictions using explanation techniques such as **SHAP** and **LIME**.

The project will compare multiple machine learning models and examine the trade-off between **model performance and interpretability**.

---

# Problem Statement

Network intrusion detection systems classify network traffic as **benign** or **malicious**. Many modern models achieve high detection performance but lack transparency, which can reduce trust and usability for cybersecurity analysts.

The problem addressed in this project is:

How can machine learning models detect network intrusions while providing interpretable explanations for their predictions?

# Explainable AI Analysis

## SHAP (SHapley Additive Explanations)

Purpose:
- measure feature contribution to predictions

Outputs:
- global feature importance
- individual prediction explanations

Example insight:

Alert: Possible DDoS attack
Top contributing features:
- Packet rate
- SYN flag count
- Flow duration

---

## LIME (Local Interpretable Model-Agnostic Explanations)

Purpose:
- explain individual predictions locally

Example explanation:

Prediction: Port scanning attack

Key factors:
+ high number of connections
+ unusual port access
+ short connection duration
